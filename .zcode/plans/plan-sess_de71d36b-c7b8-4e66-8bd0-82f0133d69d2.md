# بازطراحی پورتفولیو — حالت سایبرپانک با نئون محو

## جهت‌گیری کلی (بر اساس انتخاب‌های شما)
- **پالت:** تک‌رنگ نئون محو روی پس‌زمینه تیره — یک رنگ تاکیدی برقی (لیموی `#C2F73E`) که فقط در نقاط کلیدی استفاده می‌شود (گلوها، border‌های فعال، متن‌های مهم). بقیه سایت مونوکروم با عمق بیشتر.
- **حس کلی:** فناورانه/سایبرپانک — گرید دیجیتالی، گلو، کرسر سفارشی، افکت glitch ظریف، انیمیشن‌های سینمایی.
- **بخش جدید:** آمار و دستاوردها با انیمیشن count-up بین Skills و Projects.

## سیستم رنگ و فونت
- پس‌زمینه: `#060608` (تقریباً مشکی، کمی آبی‌تر از فعلی برای حس سردتر)
- متن اصلی: `#EDEDF0`
- متن محو: `#6B6B7C`
- **نئون:** `#C2F73E` (لیموی برقی) — به‌صورت CSS variable تا بعداً با یک خط عوض بشه
- فونت display: `Space Grotesk` (موجود) + اضافه‌کردن `JetBrains Mono` برای متن‌های مونو/کد

## فایل‌های موجود که بازنویسی/ویرایش می‌شوند

### 1. `tailwind.config.js`
- اضافه‌شدن رنگ `neon`، رنگ‌های background عمیق‌تر، رنگ‌های border
- اضافه‌شدن `boxShadow` برای گلوهای نئونی (مثل `glow-sm`, `glow-md`)
- اضافه‌شدن `animation` و `keyframes` (glitch، pulse-glow، float)

### 2. `src/index.css`
- به‌روزرسانی CSS variables با پالت جدید + متغیر `--neon`
- **افکت‌های جدید:** overlay گرید دیجیتالی ثابت، noise/grain texture نرم، کرسر سفارشی، scrollbar نئونی، scroll-behavior
- کلاس‌های کمکی: `.glow-text`, `.neon-border`, `.glass`, `.grid-bg`
- رفع `prefers-reduced-motion` برای احترام به تنظیمات کاربر

### 3. `index.html`
- اضافه‌کردن فونت `JetBrains Mono` از Google Fonts
- به‌روزرسانی meta description

### 4. `src/data/siteData.js`
- اضافه‌شدن آرایه `stats` (مثلاً: ۴ پروژه، ۲ سال تجربه، ۱۰+ تکنولوژی، ۱۰۰٪ عشق به کد 😄 — قابل ویرایش)
- حفظ داده‌های موجود (skills, projects, socialLinks)

## کامپوننت‌های بازنویسی‌شده

### 5. `ThreeBackground.jsx` — ارتقای بزرگ
- تبدیل ذرات پراکنده به **شبکه اختروشنگاری (constellation)**: ذراتی که وقتی نزدیک هم باشند با خطوط نئونی وصل می‌شوند
- wireframe shape‌ها با گلو نئونی محو به جای خاکستری
- واکنش به موس (parallax) — حفظ می‌شود اما نرم‌تر
- fade-out هنگام اسکرول — حفظ می‌شود
- کپ pixelRatio و throttling برای پرفورمنس

### 6. `Header.jsx`
- نوار پیشرفت اسکرول نئونی در بالای صفحه (ساختار جداگانه یا در همین)
- border و backdrop-blur هنگام اسکرول — حفظ می‌شود با استایل نئونی
- لینک فعال با گلو نئونی (active state با IntersectionObserver)
- لوگو با افکت hover نئونی

### 7. `Hero.jsx`
- عنوان با **افکت glitch ظریف** روی کلمه "None"
- تگ `&lt;hello_world /&gt;` با رنگ نئونی
- تایپوگرافی بزرگ‌تر و جسورانه‌تر
- دکمه primary با hover مغناطیسی + گلو نئونی
- indicator اسکرول با خط نئونی

### 8. `Skills.jsx`
- کارت‌های شیشه‌ای با border نئونی هنگام hover
- آیکون هر دسته با گلو نئونی
- tag‌های تکنولوژی با hover نئونی ظریف

### 9. **جدید:** `Stats.jsx`
- ۴ کارت آماری با **انیمیشن count-up** (راه‌اندازی با IntersectionObserver + requestAnimationFrame)
- آیکون Material Symbols برای هر آمار
- اعداد با رنگ/گلو نئونی
- background شیشه‌ای با border نازک

### 10. `Projects.jsx`
- حفظ اسکرول افقی (ویژگی خاص فعلی) اما کارت‌ها با گلو نئونی هنگام hover
- overlay گرادیان با عمق بیشتر
- تگ‌ها با border نئونی محو
- دکمه GitHub با گلو
- progress dots با نئون برای dot فعال

### 11. `Contact.jsx`
- input/textarea با focus نئونی (border + گلو) به جای خاکستری
- آیکون‌های تماس با hover نئونی
- دکمه ارسال با گلو
- لایوت حفظ می‌شود (۲ ستونی)

### 12. `Footer.jsx`
- خط بالایی نئونی محو
- متن با استایل مونو
- دکمه "back to top" با فلش و افکت نئونی

### 13. `MobileMenu.jsx`
- بازشدن با انیمیشن fade + blur (به جای toggle ساده)
- لینک‌ها با hover نئونی
- بستن با کلیک روی backdrop

## کامپوننت‌های جدید

### 14. `CustomCursor.jsx`
- نقطه کوچک نئونی + حلقه بیرونی با lag (افکت ردیابی)
- بزرگ‌شدن روی عناصر قابل‌کلیک
- فقط در دستگاه‌های با pointer دقیق (غیر موبایل) فعال می‌شود

### 15. `ScrollProgress.jsx`
- نوار نازک نئونی ثابت در بالای صفحه که درصد اسکرول رو نشون می‌دهد
- با گلو نرم

## کامپوننت والد
### 16. `App.jsx`
- اضافه‌کردن `<CustomCursor />`, `<ScrollProgress />`, `<Stats />`
- حفظ IntersectionObserver برای reveal animations

## نکات فنی
- **بدون پکیج جدید** — همه چیز با Three.js موجود + CSS + React hooks
- پرفورمنس: pixelRatio cap، throttling موس، pause انیمیشن هنگام off-screen
- دسترس‌پذیری: `prefers-reduced-motion` برای غیرفعال‌کردن انیمیشن‌های سنگین، کرسر سفارشی فقط روی دسکتاپ
- ریسپانسیو کامل حفظ می‌شود
- هیچ داده‌ای از بین نمی‌رود — فقط ظاهر و تجربه ارتقا پیدا می‌کند
